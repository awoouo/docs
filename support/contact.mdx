## 提交工单前的准备

为了让支持团队能够更快速地定位和解决您的问题，请在提交工单前准备好以下信息：

<Steps>
  <Step title="清晰描述问题">
    用简洁的语言描述您遇到了什么问题，以及问题对您的工作造成了怎样的影响。
  </Step>
  <Step title="提供复现步骤">
    按顺序列出触发问题所需的具体操作步骤，例如："1. 前往设置页面 → 2. 点击新建 API 密钥 → 3. 出现 500 错误"。可复现的问题能显著缩短排查时间。
  </Step>
  <Step title="附上错误截图或错误信息">
    截取浏览器中显示的错误页面，或复制完整的错误提示文本。如果是 API 错误，请附上完整的响应体内容。
  </Step>
  <Step title="提供 API request_id">
    每次 API 调用的响应体中均包含 `meta.request_id` 字段，格式类似 `req_abc123xyz`。支持团队可凭此在服务端日志中精确定位您的请求记录。
  </Step>
  <Step title="说明浏览器和操作系统版本">
    前端问题往往与浏览器或系统环境有关，请提供您的浏览器名称及版本号（如"Chrome 125.0"）以及操作系统版本（如"macOS 14.5"或"Windows 11"）。
  </Step>
</Steps>

## 支持服务级别

不同套餐享有不同的响应时间承诺和支持渠道，请参考下表：

| 套餐 | 响应时间承诺 | 支持渠道 |
|------|-------------|----------|
| 免费版 | 5 个工作日 | 工单、社区论坛 |
| 专业版 | 1 个工作日 | 工单、邮件、在线聊天 |
| 企业版 | 4 小时 | 专属技术顾问、工单、电话 |

响应时间从工单提交或邮件发送时起算，工作日为周一至周五（法定节假日除外）。

## 企业版支持

企业版客户将享有 ACS 最高级别的支持服务，确保您的业务运行无后顾之忧：

- **专属技术顾问**：每位企业客户将分配一名专属技术顾问，负责日常沟通、需求对接和问题升级，全程跟进您的技术诉求。
- **4 小时响应 SLA**：针对 P1 级别（服务不可用）故障，我们承诺在 **4 小时内**给出首次响应，并持续跟进至问题解决。
- **电话支持**：提供专线电话支持，适合需要即时沟通的紧急情况。
- **定期业务回顾**：每季度与您的技术顾问进行使用情况回顾和产品规划对齐，确保 ACS 的发展方向始终契合您的业务需要。
- **SLA 保障协议**：提供书面服务级别协议（SLA），明确可用性指标及补偿方案，为您的业务连续性提供制度保障。

如需了解企业版定价和定制方案，请联系我们的销售团队：**sales@acs.com**，或拨打企业热线（在控制台登录后可见）。
