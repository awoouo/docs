## 账号与登录

<AccordionGroup>
  <Accordion title="如何重置密码？">
    如果您忘记了登录密码，请按照以下步骤操作：

    1. 打开 ACS 信息中心登录页面。
    2. 点击密码输入框下方的 **忘记密码？** 链接。
    3. 在跳转页面中输入您注册时使用的邮箱地址，然后点击 **发送重置邮件**。
    4. 请检查您的收件箱（若未收到，请同时检查垃圾邮件文件夹），点击邮件中的重置链接。
    5. 按照页面提示设置新密码，完成后即可使用新密码登录。

    重置链接的有效期为 **30 分钟**，过期后需重新发起申请。
  </Accordion>

  <Accordion title="如何修改绑定的邮箱？">
    您可以在账号设置中更改绑定邮箱：

    1. 登录后点击右上角头像，选择 **设置**。
    2. 进入 **账号** 标签页。
    3. 在 **邮箱地址** 栏旁点击 **修改**。
    4. 输入新邮箱地址，系统将向新邮箱发送一封验证邮件。
    5. 打开验证邮件并点击确认链接，修改即刻生效。

    请注意：修改邮箱后，下次登录需使用新邮箱地址。
  </Accordion>

  <Accordion title="如何删除账号？">
    账号删除操作不可逆，且会同时清除您在所有工作空间中的相关数据。出于数据安全考虑，ACS 不支持用户自助删除账号，您需要联系支持团队提出申请：

    - 发送邮件至 **support@acs.com**，邮件主题请填写"申请删除账号"。
    - 邮件中请注明您的注册邮箱及删除原因。

    支持团队将在 **3 个工作日**内处理您的申请，并在操作前与您二次确认。
  </Accordion>

  <Accordion title="一个账号可以加入多少个工作空间？">
    单个账号最多可同时加入 **50 个工作空间**。如果您的业务需求超出此限制，请联系 ACS 企业销售团队，我们可为企业版客户提供定制化配置方案。
  </Accordion>
</AccordionGroup>

## API 与集成

<AccordionGroup>
  <Accordion title="API 密钥丢失了怎么办？">
    出于安全考虑，ACS 不会存储 API 密钥的明文，因此**无法找回已生成的密钥**。如果您丢失了密钥，请按以下步骤重新创建：

    1. 前往 **设置 → API → 密钥管理**。
    2. 找到丢失的密钥条目，点击 **撤销** 将其作废，防止被他人滥用。
    3. 点击 **新建密钥**，为其命名并选择适当的权限范围。
    4. 新密钥仅在创建时显示一次，请立即复制并妥善保存（建议存入密码管理工具）。

    <Warning>
      请勿将 API 密钥提交至代码仓库或以明文形式存储在配置文件中。建议通过环境变量或密钥管理服务进行管理。
    </Warning>
  </Accordion>

  <Accordion title="如何查看 API 请求日志？">
    您可以在控制台中查看最近的 API 调用记录：

    1. 前往 **设置 → API → 请求日志**。
    2. 日志记录包括：请求时间、接口路径、HTTP 状态码、响应耗时及 `request_id`。
    3. 支持按时间范围、状态码和密钥筛选，方便您快速定位问题。

    免费版日志保留最近 **7 天**，专业版及以上保留 **90 天**。
  </Accordion>

  <Accordion title="免费版有 API 调用次数限制吗？">
    是的，免费版账号每天最多可发起 **1,000 次** API 调用（按自然日 UTC 00:00 重置）。超出限额后，接口将返回 `429 Too Many Requests` 错误，直至次日配额重置。

    如需更高调用量，您可以升级至专业版（10,000 次/天）或企业版（自定义配额）。详见[套餐对比](https://acs.com/pricing)页面。
  </Accordion>

  <Accordion title="支持 OAuth 2.0 吗？">
    目前 ACS API 仅支持通过 **API 密钥**（Bearer Token）进行认证。OAuth 2.0 授权码流程已列入产品路线图，预计于 **Q3** 正式推出，届时将支持代表用户发起 API 请求的场景。

    如果您希望提前了解 OAuth 集成的技术细节，欢迎加入[社区论坛](https://community.acs.com)参与讨论，或联系您的专属技术顾问（企业版）。
  </Accordion>
</AccordionGroup>

## 应用入口

<AccordionGroup>
  <Accordion title="为什么看不到某个应用？">
    如果您在应用中心无法看到某个应用，可能有以下几种原因：

    - **权限未开通**：该应用可能需要管理员单独授权，请联系您的工作空间管理员申请访问权限。
    - **应用未启用**：管理员可能尚未在工作空间中启用该应用。
    - **套餐限制**：部分高级应用仅对专业版或企业版用户开放。

    如有疑问，请先咨询您的工作空间管理员，确认应用的可用状态。
  </Accordion>

  <Accordion title="如何申请新应用的访问权限？">
    申请流程非常简便：

    1. 在应用中心找到您希望访问的应用卡片（即使无权限也可见，但会显示锁定状态）。
    2. 点击应用卡片上的 **申请权限** 按钮。
    3. 填写申请理由，提交后系统将自动通知您的工作空间管理员。
    4. 管理员审批通过后，您将收到邮件通知，刷新页面即可访问该应用。

    审批通常在 **1 个工作日**内完成，具体时效取决于您的组织内部流程。
  </Accordion>

  <Accordion title="应用图标显示不出来怎么办？">
    应用图标无法显示通常由以下原因导致：

    - **图片格式不支持**：ACS 仅支持 PNG、JPG、SVG 和 WebP 格式。
    - **图片 URL 失效**：如果图标使用外链 URL，请确认该链接可公开访问且未过期。
    - **图片尺寸不符**：建议上传尺寸为 **128×128 像素** 及以上的正方形图片。

    **解决方法：**
    1. 前往 **应用管理 → 编辑应用 → 图标设置**。
    2. 重新上传本地图片文件，或粘贴符合格式要求的公开访问 URL。
    3. 保存后刷新页面确认图标正常显示。
  </Accordion>
</AccordionGroup>

## 主页与文档中心

<AccordionGroup>
  <Accordion title="主页上显示的内容是什么？">
    ACS 信息中心主页是您登录后看到的第一个页面，展示您最近访问的应用、工作空间动态、系统公告以及快捷入口。主页内容会根据您的权限和使用习惯动态调整，帮助您快速进入常用功能区域。
  </Accordion>

  <Accordion title="如何使用文档中心？">
    文档中心收录了 ACS 信息中心的完整产品文档，包括功能说明、API 参考、集成指南与最佳实践。您可以通过顶部导航栏进入文档中心，使用搜索框快速定位所需内容，或按照左侧目录结构逐级浏览。所有文档均可免费访问，无需登录。
  </Accordion>

  <Accordion title="文档中心的内容多久更新一次？">
    文档中心随产品版本同步更新，通常在新功能发布后的 1–2 个工作日内完成对应文档的更新。如果您发现文档与实际产品行为不符，欢迎通过[联系我们](/support/contact)页面反馈，帮助我们持续改进文档质量。
  </Accordion>
</AccordionGroup>

## 博客与体验中心

<AccordionGroup>
  <Accordion title="ACS 博客发布哪些内容？">
    ACS 博客定期发布产品更新公告、功能使用技巧、行业洞察与开发者实践案例。您可以通过顶部导航栏进入博客页面，按分类或标签筛选感兴趣的文章。订阅博客可在新文章发布时第一时间收到邮件通知。
  </Accordion>

  <Accordion title="体验中心是什么？如何使用？">
    体验中心提供 ACS 信息中心核心功能的在线演示环境，无需完整注册即可直观体验产品能力。您可以在体验中心试用应用入口管理、API 调用、文档搜索等功能，帮助您在正式使用前评估产品是否满足需求。进入体验中心请点击顶部导航栏中的 **体验中心** 入口。
  </Accordion>

  <Accordion title="体验中心的数据是真实数据吗？">
    不是。体验中心使用的是预置的演示数据，与您的生产账号完全隔离。在体验中心内的任何操作都不会影响您的实际账号数据或计费状态。演示数据会定期重置以保持演示环境的整洁。
  </Accordion>
</AccordionGroup>

## 计费

<AccordionGroup>
  <Accordion title="有免费版吗？">
    是的，ACS 信息中心提供永久免费版套餐，无需绑定信用卡即可注册使用。免费版包含以下核心功能：

    - 最多 **3 个**工作空间成员
    - 每日 **1,000 次** API 调用
    - **7 天**日志保留
    - 访问基础应用入口

    如需解锁更多功能和更高用量，您可以随时升级至专业版或企业版。
  </Accordion>

  <Accordion title="如何升级套餐？">
    升级套餐仅需几步操作：

    1. 登录后点击右上角头像，选择 **设置**。
    2. 进入 **计费** 标签页。
    3. 点击 **升级套餐**，对比各版本功能后选择适合您的方案。
    4. 选择付款方式并完成支付，升级即刻生效。

    如需了解企业版定制方案或批量采购优惠，请联系我们的销售团队：sales@acs.com。
  </Accordion>

  <Accordion title="支持哪些付款方式？">
    ACS 信息中心目前支持以下付款方式：

    - **微信支付**：扫码支付，支持个人及企业账户
    - **支付宝**：扫码或账户余额支付
    - **银行转账**：适合企业客户，需提前联系财务团队获取对公账户信息

    所有付款均支持开具增值税发票（普通发票或专用发票），请在支付完成后前往 **设置 → 计费 → 发票管理** 提交开票申请。
  </Accordion>
</AccordionGroup>
