**体验中心（Experience Center）**是 ACS 信息中心为每位用户提供的专属沙箱环境。它与您的生产工作空间完全隔离，使用独立的模拟数据、专用的测试 API 密钥，以及预置的演示应用——您可以在这里随意点击、随意配置、随意调用 API，无论做什么操作，都不会影响任何真实的业务数据或线上服务。体验中心完全**免费开放**，是您熟悉平台功能、验证集成方案或向团队演示产品能力的理想场所。

## 体验中心与生产环境的区别

了解两者的差异，有助于您在正确的场景中使用正确的环境：

| 特性 | 体验中心 | 生产环境 |
|------|----------|----------|
| **数据** | 模拟数据（系统预置，仅供演示） | 真实业务数据 |
| **API 密钥** | 专用测试密钥（以 `sk_test_` 开头） | 生产密钥（以 `sk_live_` 开头） |
| **应用** | 演示应用（预配置的示例入口） | 您的正式注册应用 |
| **费用** | 完全免费，无使用限制 | 按实际使用量计费 |
| **数据持久性** | 每 7 天自动重置一次 | 永久保存，除非主动删除 |

## 如何进入体验中心

<Steps>
  <Step title="登录 ACS 信息中心">
    使用您的账号登录 ACS 信息中心。如果您尚未注册，可以免费创建账号，体验中心在注册后即可立即使用，无需任何额外申请。
  </Step>
  <Step title="点击顶部导航栏中的体验中心">
    登录后，在页面顶部导航栏中找到并点击 **体验中心（Experience Center）** 入口。系统将自动切换至沙箱上下文，页面顶部会出现醒目的标识，提示您当前处于体验环境中，以区别于生产环境。
  </Step>
  <Step title="自由探索所有功能">
    进入体验中心后，您可以像使用正式账号一样操作平台的所有功能——浏览演示应用、调用沙箱 API、测试权限配置、体验文档搜索等。所有操作均基于模拟数据，您可以放心探索，不必担心对真实业务造成任何影响。
  </Step>
</Steps>

## 沙箱 API 基础地址

在体验中心中调用 API 时，请使用专用的沙箱基础地址，而非生产环境的 API 地址：

```
https://sandbox.api.acs.com/v1
```

例如，在沙箱环境中获取应用列表的完整请求如下：

```bash
curl -X GET https://sandbox.api.acs.com/v1/applications \
  -H "Authorization: Bearer sk_test_YOUR_SANDBOX_KEY"
```

<Note>
  沙箱环境的 API 密钥均以 **`sk_test_`** 开头，生产环境的 API 密钥以 **`sk_live_`** 开头。两者不可混用——使用生产密钥访问沙箱地址，或使用测试密钥访问生产地址，均会返回鉴权错误。您可以在体验中心的 **API 密钥** 页面找到专属的沙箱密钥。
</Note>

## 常见体验场景

以下是一些在体验中心中最受欢迎的探索场景，点击展开了解具体操作方式：

<AccordionGroup>
  <Accordion title="测试 API 集成">
    体验中心是调试 API 集成逻辑的最佳场所。您可以使用沙箱 API 密钥（`sk_test_`）和沙箱基础地址，在不动用任何生产数据的情况下完整走通注册应用、拉取列表、更新配置等 API 调用流程。

    建议在正式将集成代码部署到生产环境之前，先在沙箱中完成端到端验证，确认请求格式、响应结构和错误处理逻辑均符合预期。
  </Accordion>
  <Accordion title="演示应用入口">
    体验中心预置了多个演示应用，覆盖内部应用、外部 SaaS 和自建应用等常见类型。您可以以此为蓝本，向团队成员或管理层展示信息中心的统一入口能力，直观呈现"所有应用一处访问"的使用体验，无需提前准备真实的生产数据。

    您也可以在体验中心中自行注册演示应用，调整图标、描述和权限设置，预演正式上线前的配置方案。
  </Accordion>
  <Accordion title="体验文档搜索">
    ACS 信息中心内置了覆盖全平台的文档搜索功能。在体验中心中，您可以充分体验文档检索的速度与准确性——输入关键词、按类别筛选、查看高亮匹配结果，感受文档中心为团队成员带来的知识获取效率提升。

    文档内容在体验中心与生产环境中完全一致，您在此处找到的任何文档条目，在生产环境中同样可以检索到。
  </Accordion>
</AccordionGroup>

<Warning>
  体验中心的沙箱数据**每 7 天自动重置一次**，届时您在沙箱中创建的应用、配置和 API 密钥将全部清除并恢复至初始状态。请勿将体验中心用于任何生产目的，也不要在沙箱中存储真实的业务数据或依赖沙箱 API 密钥运行正式服务。
</Warning>
