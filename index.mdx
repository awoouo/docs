## 快速上手

<Steps>
  <Step title="注册账号">
    前往 [控制台](https://app.acs.com) 注册您的 ACS 账号。注册仅需邮箱和密码，几秒即可完成。
  </Step>
  <Step title="获取 API 密钥">
    登录后进入 **账号设置 → API 密钥**，点击 **创建密钥** 生成您的第一个 API 密钥。妥善保存，密钥仅显示一次。
  </Step>
  <Step title="发起第一个请求">
    使用您的 API 密钥调用 ACS API，验证集成是否成功。详见 [快速开始](/quickstart) 指南。
  </Step>
  <Step title="探索应用入口">
    在 [应用入口](/guides/app-access) 中找到您有权访问的所有业务应用，一键直达。
  </Step>
</Steps>
