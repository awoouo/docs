---

ACS 信息中心的**应用入口**是您访问所有业务系统的统一起点。无论是企业内部部署的 OA 办公系统、CRM 客户管理平台、ERP 资源规划系统，还是团队自行搭建的业务工具，都会集中展示在这里。您无需记忆各系统的独立网址或维护一份书签列表——只需登录 ACS 信息中心，便能从同一个界面一键跳转到任意有权访问的应用，真正实现"一个入口，掌管全局"。

## 访问应用入口

<Steps>
  <Step title="登录 ACS 信息中心">
    使用您的企业账号登录 ACS 信息中心。如果您所在的企业已启用单点登录（SSO），可直接通过企业身份认证完成登录，无需额外输入密码。
  </Step>
  <Step title="进入应用入口">
    登录成功后，单击顶部导航栏中的"**应用入口**"标签。页面将加载您当前有权访问的所有业务应用，以卡片网格的形式展示。
  </Step>
  <Step title="浏览或搜索应用">
    您可以直接在页面中滚动浏览所有应用，也可以使用页面顶部的搜索栏输入应用名称快速定位目标系统。搜索支持模糊匹配，输入部分名称即可显示相关结果。
  </Step>
  <Step title="单击应用卡片打开">
    找到目标应用后，单击其卡片即可在新标签页中打开该应用。部分应用支持在信息中心内嵌框架内直接使用，无需跳转至外部页面。
  </Step>
</Steps>

## 搜索与筛选应用

当您的工作空间中接入的应用数量较多时，搜索与筛选功能能帮助您快速定位所需系统：

**按名称搜索**
在应用入口页面顶部的搜索栏中输入应用名称的全称或关键词。搜索结果将实时过滤，仅展示名称或描述中包含该关键词的应用。

**按分类筛选**
单击搜索栏下方的分类标签，可按照以下类别筛选应用：

| 分类标签 | 说明 |
|----------|------|
| **OA** | 办公自动化系统，如审批流、日程管理等 |
| **CRM** | 客户关系管理平台 |
| **ERP** | 企业资源规划系统 |
| **自建** | 企业或团队自行开发并接入的内部工具 |

多个分类标签可同时选中以进行组合筛选。您也可以随时从 ACS 信息中心的任意页面按下 `Ctrl + K` 唤起全局搜索，直接检索应用名称，无需先进入应用入口页面。

## 收藏常用应用

对于每天都会用到的核心系统，建议将其添加到收藏，以便更快访问：

将鼠标悬停在任意应用卡片上，卡片右上角会出现一个**星形图标**（☆）。单击该图标即可将此应用添加到收藏。收藏后，图标变为实心星形（★），且该应用将自动出现在应用入口顶部的"**我的收藏**"区域，始终置顶显示，无需每次都在完整列表中滚动查找。

如需取消收藏，再次单击已高亮的星形图标即可将其从收藏区移除。

## 申请应用权限

如果您在应用入口看到某个应用，但无法直接单击打开（卡片显示为半透明或带有锁形图标），说明您目前尚未获得该应用的访问权限。您可以通过以下步骤发起权限申请：

1. 单击该应用卡片上的"**申请权限**"按钮。
2. 在弹出的申请表单中填写申请理由（部分工作空间要求必填），并选择所需的权限级别（如"只读"或"编辑"）。
3. 单击"**提交申请**"，系统将自动将申请通知发送给该应用的管理员进行审核。
4. 管理员审批通过后，您将收到站内通知与邮件提醒，届时即可正常访问该应用。

如果申请长时间未得到处理，请联系您的 IT 管理员或应用所有者。

## 应用状态说明

应用卡片上有时会显示状态标识，帮助您了解当前系统的可用情况：

| 状态 | 含义 |
|------|------|
| **正常** | 应用运行正常，可直接单击访问 |
| **维护中** | 应用暂时不可用，预计恢复时间请查看公告中心的维护通知 |
| **权限不足** | 您尚未获得该应用的访问权限，需提交申请后等待管理员审批 |

<Tip>
  在 ACS 信息中心的任意页面，按下 **Ctrl + K** 即可唤起全局搜索。直接输入应用名称，无需先进入应用入口页面，便可快速找到并跳转至目标应用，是日常工作中最高效的访问方式之一。
</Tip>
