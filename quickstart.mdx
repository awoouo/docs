本指南将带领您从零开始，完成 ACS 信息中心的账号注册与工作空间创建，获取专属 API 密钥，并通过一条真实的 API 请求验证接入是否成功。整个过程预计只需 **5 分钟**，无需任何复杂配置。完成后，您将拥有一个完整可用的 ACS 账号，并能够通过 API 访问您的应用列表，为后续的深度集成奠定基础。

<Steps>
  <Step title="注册账号">
    打开浏览器，访问 [https://app.acs.com](https://app.acs.com)，点击页面右上角的**立即注册**按钮。

    在注册表单中填写以下信息：
    - **邮箱地址**：请使用企业邮箱，以便后续与团队成员协作
    - **登录密码**：至少 8 位，建议包含大小写字母、数字与特殊字符

    提交后，系统将向您的邮箱发送一封验证邮件。请在 **10 分钟内**点击邮件中的确认链接以激活账号。若未收到邮件，请检查垃圾邮件文件夹，或点击注册页面上的**重新发送验证邮件**。
  </Step>

  <Step title="创建工作空间">
    邮箱验证完成后，系统将自动引导您进入工作空间创建流程。工作空间是您在 ACS 信息中心中的独立管理单元，所有应用配置、API 密钥与团队成员均归属于特定工作空间。

    在创建页面中：
    1. 在**工作空间名称**字段中输入一个便于识别的名称，例如"张三的开发环境"或"XX 公司生产环境"
    2. 选择适合您团队规模的**套餐类型**（初次使用可选免费套餐）
    3. 点击**创建工作空间**完成设置

    创建成功后，您将进入工作空间的主控制台，可在此管理所有资源。
  </Step>

  <Step title="获取 API 密钥">
    API 密钥是您调用 ACS 接口时的身份凭证，请妥善保管，切勿泄露给他人。

    按以下路径获取密钥：

    1. 点击控制台左侧导航栏底部的**设置（Settings）**
    2. 在设置页面中选择 **API Keys** 选项卡
    3. 点击右上角的**创建密钥（Create Key）**按钮
    4. 在弹出窗口中为密钥输入一个描述性名称（例如"本地开发测试"），然后点击**确认**
    5. 系统将生成并展示您的 API 密钥，格式为 `acs_live_xxxxxxxxxxxxxxxxxx`

    <Warning>
      此密钥**仅在创建时显示一次**，请立即将其复制并保存到安全的位置（如密码管理工具）。若不慎丢失，您需要重新创建新密钥。
    </Warning>
  </Step>

  <Step title="发起第一个 API 请求">
    现在，使用您刚刚获取的 API 密钥，通过以下 `curl` 命令查询当前工作空间下的应用列表：

    ```bash
    curl -X GET https://api.acs.com/v1/applications \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -H "Content-Type: application/json"
    ```

    将 `YOUR_API_KEY` 替换为您在上一步中复制的密钥值。请求成功后，您将收到类似如下的 JSON 响应：

    ```json
    {
      "data": [
        {
          "id": "app_001",
          "name": "OA 系统",
          "url": "https://oa.acs.com",
          "status": "active"
        },
        {
          "id": "app_002",
          "name": "CRM",
          "url": "https://crm.acs.com",
          "status": "active"
        }
      ],
      "total": 2
    }
    ```

    响应中的 `data` 数组包含您工作空间下所有已配置的应用，每条记录包含应用 ID、名称、访问地址与当前状态。`total` 字段表示应用总数。若返回空数组，说明当前工作空间尚未添加任何应用，请先通过控制台的**应用入口**模块完成配置。
  </Step>

  <Step title="探索应用入口">
    恭喜您！API 接入已成功验证。接下来，您可以前往[应用入口使用指南](/guides/app-access)，深入了解如何在控制台中添加、配置和管理业务应用，以及如何为团队成员分配不同应用的访问权限，充分发挥 ACS 信息中心的统一入口优势。
  </Step>
</Steps>

<Tip>
  建议您在正式将 ACS 集成到生产环境之前，先前往**体验中心**进行沙箱测试。体验中心提供与生产环境完全隔离的演示数据，您可以在不影响任何真实业务数据的前提下，自由测试 API 接口行为、探索平台各项功能，是验证集成方案的理想选择。
</Tip>
